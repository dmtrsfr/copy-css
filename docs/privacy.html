Privacy Policy for Copy CSS

Last updated: 2026-09-15

Copy CSS does not collect, store, or transmit any personal data or browsing information. All processing happens locally in your browser, on the tab you activate the extension on.

What Data We Collect

None. The extension reads the HTML and computed styles of an element you click, formats them into a snippet, and copies that snippet to your system clipboard. Nothing is saved, logged, or sent anywhere.

How Data Is Stored

Not applicable — no data is stored, either locally or remotely.

Third-Party Services

This extension does not use any third-party services, analytics, or tracking of any kind.

Data Sharing

No data is collected, so none is shared with anyone.

Permissions

activeTab and scripting are used only to inject the element-picker into the tab you're viewing when you click the extension's toolbar icon. Neither permission is used to read or transmit data from any other tab.

Changes to This Policy

If this extension's data practices ever change, this page will be updated accordingly.
